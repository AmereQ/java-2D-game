# Java Swing Game

A simple 2D arcade-style game written in Java using the Swing GUI library.

## 🎮 About the Game

- The player can move left and right to avoid falling enemies.
- Each time enemies reach the bottom, the score increases.
- The game becomes faster and harder over time.
- Game ends when the player touches an enemy – press `Enter` to restart.

## 🛠️ Technologies Used

- Java 8+
- Swing (javax.swing)
- Object-Oriented Programming
- Simple 2D rendering with `Graphics`

## ▶️ How to Run

1. Make sure you have Java 8 or newer installed
2. Compile all `.java` files:

   ```bash
   javac *.java
